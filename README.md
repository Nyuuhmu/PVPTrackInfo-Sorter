# PVPTrackInfo-Sorter

Sorts the entries of Driftcity's `PVPTrackInfo.xlt` file in order of city and index. 

## How to use

Drag the `PVPTrackInfo.xlt` file onto the `PVPTrackInfo-Sorter.exe`, the program will then sort the entries and produce a new `..._sorted.xlt` file that can be renamed and used.
